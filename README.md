# Toolbox v2

A Fabric client framework for module tools, categories, settings and favorites, with a Skia interface powered by Squid.

This branch targets Minecraft 26.2 and Java 25. Run `gradlew.bat build` to build and test, or `gradlew.bat runUiTest` for the isolated development showcase. Building uses the sibling Minecraft 26.2 Squid checkout by default.

See [MIGRATION.md](MIGRATION.md) for architecture, dependencies, API changes, installation and validation details.
